# 随听 · SuiTing

> 给日常留一点音乐。

随听是一款面向个人使用的 Android 音乐播放器，基于 [CharlesPikachu/musicsquare](https://github.com/CharlesPikachu/musicsquare) 的音乐搜索适配思路改造。它将多来源搜索、本地音乐、同步歌词和歌单管理放进简洁的手机界面，并通过 Android 原生播放服务提供后台播放。

界面采用深墨绿色与浅绿色搭配，包含「发现」「正在播放」「我的音乐」三个页面。应用不设账号系统，不含广告和统计 SDK，本地音频不会被上传。

## 功能特性

### 发现与搜索

- 支持网易云、QQ 音乐、酷我的单曲搜索，允许同时选择多个来源。
- 搜索类型可切换为「单曲」「歌手」「歌单」；歌手和歌单搜索当前接入网易云。
- 单曲默认每个来源返回 20 首，支持加载更多与歌曲 ID 去重。
- 首页展示网易云精选歌单，可切换热门歌曲；清空搜索后恢复推荐内容。
- 歌手详情提供平台热门歌曲，在线歌单支持分批加载和播放已加载曲目。

首页推荐属于平台精选内容，当前没有基于个人收听习惯的推荐算法。

### 播放与歌词

- 原生音频播放，支持后台播放、系统媒体会话与通知栏控制。
- 支持上一首、下一首、进度跳转、列表循环、单曲循环和随机播放。
- 默认显示封面，点击后翻转到歌词，支持返回封面。
- 当前播放句居中高亮，点击同步歌词可跳到对应位置继续播放。
- 手动滑动、按住和惯性滚动期间暂停自动跟随，停止浏览约 1.5 秒后恢复。
- 缺少同步歌词时，可联网搜索，按歌名、歌手和时长匹配；不确定的版本需要确认。
- 纯文本歌词明确标注，不会生成虚假的同步时间轴。

### 我的音乐

- 收藏喜欢的歌曲，创建本地歌单，并向歌单添加或移除歌曲。
- 使用系统文件选择器导入手机音频，支持格式取决于设备与解码器。
- 收藏在线歌单引用，后续打开时重新读取在线内容。
- 将在线歌单中已加载的曲目保存为本地歌单快照。
- 使用 JSON 文件导入、导出歌单，导入时合并去重。

「本地歌单快照」保存当时已加载的歌曲记录，不会随在线歌单自动更新；「在线歌单收藏」保存来源和 ID，依赖网络读取。

### 手机界面适配

- 播放页固定在一屏内，封面与歌词区域根据可用高度伸缩。
- 「我的音乐」的操作按钮和分类固定，只有当前标签下的列表滚动。
- 播放页右上角为加入歌单，底部右侧为播放队列。
- 搜索和音乐库页面保留迷你播放器；进入播放页后隐藏。
- 键盘弹出时隐藏迷你播放器和底部导航，收起键盘后恢复。

## 使用说明

### 搜索与播放

在「发现」页输入关键词，选择搜索类型与音乐来源，点击搜索或使用键盘搜索键提交。点击单曲开始播放，通过歌曲右侧菜单收藏或加入歌单。

歌手和歌单模式当前使用网易云目录，界面会显示来源提示，并暂时禁用其他来源选择；切回单曲模式后恢复原有来源选择。搜索失败会显示错误和重试入口，正常空结果与服务错误分别提示。

### 歌词与联网补充

进入「正在播放」，点击封面切换歌词。同步歌词支持高亮、滑动浏览和点击跳播。没有歌词时，点击「联网搜索歌词」；若本地文件的歌名或歌手不准确，可以先修改搜索信息。

不同录音版本可能存在时长和时间轴差异。对于匹配不明确的结果，核对候选后再应用；只有纯文本的结果不能按句跳播。

### 本地音乐与备份

进入「我的音乐」，点击上方「本地音乐」选择音频文件。应用只保存文件引用，不复制或上传原音频；移动、删除原文件或撤销文件访问权限后，需要重新导入。

点击右上角信息按钮打开「关于随听」，在面板底部使用「导出歌单」「导入歌单」。导出内容是歌曲记录、歌单及在线歌单引用，**不包含音频文件、播放地址缓存或歌词缓存**。换手机后，本地音频通常需要重新选择。

## 播放解析与缓存

### 网易云按需解析

没有可复用地址、也没有近期试听记录时，先请求网易云原接口。原接口能提供完整音频时直接使用；返回试听、无地址或接口异常时，再尝试第三方解析。

如果接口没有明确标注试听，播放器会在取得实际音频时长后继续判断。检测到明显短于整曲的片段时，补试一次第三方解析；第三方失败时保留试听提示，不将片段显示为完整版。

第三方解析使用原网易云歌曲 ID，核对返回的歌曲 ID、元数据时长与音频域名，不自动替换为 QQ、酷我的同名歌曲。实际短试听判断会结合整曲时长，避免把本身只有几十秒的歌曲误判为试听。

### 短期播放地址缓存

重复播放时优先复用有效地址，减少取链接口的等待。缓存地址播放失败后会清除并自动重新获取一次；缓存仅保存地址和必要元数据，不保存音频内容。

| 缓存项目 | 当前策略 |
| --- | --- |
| 网易云播放地址 | 最长 10 分钟 |
| QQ、酷我播放地址 | 最长 5 分钟 |
| 可识别的网易云签名期限 | 到期前 30 秒失效，与默认期限取较短值 |
| 明确确认的网易云试听状态 | 记住 30 分钟，优先尝试第三方解析 |
| 保存数量 | 播放地址最多 80 条，试听记录最多 120 条 |

普通网络失败不会被记成「只能试听」。缓存和试听记录保存在本机，可跨进程重启保留；首次播放仍需要取链，命中缓存后也仍需要连接音频服务器和缓冲，因此不承诺点击后立即出声。

## 技术实现

本地 HTML/CSS/JavaScript 构成手机界面，通过受控 JavaScript 桥接调用 Android 功能。音乐源请求由原生 Java 适配器完成，音频由 Media3 服务播放，避免把后台播放生命周期交给 WebView。

| 模块 | 作用 |
| --- | --- |
| `MainActivity.java` | WebView 容器、原生桥接、系统文件选择、歌单持久化与键盘状态同步 |
| `PlaybackService.java` | Media3 播放服务、队列、媒体会话、播放状态和异步结果隔离 |
| `MusicApi.java` / `QQSearch.java` | 单曲搜索、资源获取与不同来源字段归一化 |
| `NeteaseResolver.java` | 网易云原接口与第三方解析的按需切换 |
| `PlaybackCache.java` | 播放地址缓存、过期处理与近期试听记录 |
| `CatalogApi.java` | 网易云推荐、歌手和歌单目录、详情与分页 |
| `LyricsSearch.java` | 联网歌词查询、版本匹配及候选结果 |
| `app/src/main/assets/` | 界面、主题、歌词交互与发现页逻辑 |
| `app/src/test/` / `qa/` | Java 回归测试、浏览器交互脚本与验证记录 |

本地资料使用 SharedPreferences 中的 JSON 保存，尚未引入 Room 数据库。播放队列保存在服务内存中，系统杀死进程后不会自动恢复。

## 测试与已知限制

当前工程有 59 项 Java 回归测试，覆盖音乐源适配、歌词匹配、播放地址缓存、试听处理和目录解析。浏览器交互检查覆盖分类搜索、推荐、分页、歌单、歌词、固定布局及键盘状态切换。

目录与缓存取链曾使用生产 Java 适配代码进行联网验证。浏览器测试使用模拟原生桥接；0.1.10 的键盘行为通过模拟原生状态通知验证，尚未完成新的安卓真机键盘验证。这些检查不能代替不同手机、网络和系统省电策略下的实际体验测试。

当前限制包括：

- 歌手、歌单搜索及首页推荐仅接入网易云。
- 匿名目录接口可能只提供部分歌单曲目，界面按已加载和可获取数量显示。
- 没有账号系统、云同步、音频离线下载、桌面歌词和桌面小组件。
- 外部接口可能变更或失效；平台返回的试听、权限及地区限制仍可能影响播放。
- 本地音频格式、后台存活和锁屏体验受设备及系统设置影响。

## 常见问题

### 为什么搜到歌曲却不能播放？

搜索获取的是歌曲信息，实际播放还需要有效音频地址。遇到超时、空地址或资源失效，可先重试，再尝试其他来源；缓存地址失败时应用会自动重新取链一次。

### 为什么第一次播放仍有等待？

首次播放需要请求接口，部分网易云歌曲还需要第三方解析，之后才能连接和缓冲音频。缓存主要改善同一首歌曲再次播放的取链速度。

### 网易云是否保证全部完整可听？

不保证。应用会按需尝试解析并检测短试听，最终以实际返回的音频为准。试听片段仍会明确提示，不会通过修改界面时长冒充完整歌曲。

### 收藏在线歌单与保存本地歌单有什么区别？

收藏在线歌单保留来源和 ID，打开时读取在线内容；保存本地歌单则把当前已加载的曲目存成独立快照。尚未加载的曲目不会自动包含在快照里。

### 为什么本地歌曲换手机后不能直接播放？

备份保存的是原设备的文件引用，而非音频文件。请把音频转移到新设备，并重新选择本地文件。

### 为什么输入时底部播放器和导航消失了？

这是为键盘和输入区域腾出空间的处理，音乐仍继续播放。键盘收起后，底部控件按当前页面状态恢复。
